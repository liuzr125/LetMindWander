# 公告功能增量设计（MySQL 5.7.25）

基于现有 V3.16 系列管理权限与审计表增量扩展，旧版本不改动。与词学习增量独立，可在管理员表已创建后执行 SQL/知行日课_公告功能增量_MySQL5.7.25.sql。未执行真实数据库迁移。

announcement：id CHAR(32) 主键；title VARCHAR(120)；body TEXT（应用限制 20000 字）；state VARCHAR(16) 为 draft/published/withdrawn；publish_at 可空 TIMESTAMP(3)；created_by、updated_by 为管理员 ID；created_at、updated_at 为时间。索引 (state,publish_at)。正文按纯文本展示，无 HTML 执行。

用户接口需登录，只返回 published 且 publish_at 不晚于服务器当前时刻的公告，按发布时间倒序，详情使用同一可见性条件。未来发布时间到点自动可见，不依赖调度任务。撤回立即隐藏，草稿不暴露。后台所有保存操作与 admin_audit 一起事务提交，存状态、操作者和目标 ID，不保存正文副本。新菜单 announcements 默认仅授予超级管理员，可沿用角色管理授权其他管理员。

发布时间 API 使用带时区 ISO 8601，管理端按北京时间录入展示。数据不包含任何真实公告。

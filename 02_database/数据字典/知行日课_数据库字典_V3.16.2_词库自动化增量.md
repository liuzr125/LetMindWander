# 知行日课数据库字典 V3.16.2 词库自动化增量

适用基线：V3.16。对应实施脚本：`05_code/backend/sql/V3.16.2_vocabulary_import_automation.sql`。

本次新增四张“词库导入暂存层”表。它们只记录数据源、批次过程、行级审核和音频任务；正式发布后的内容仍落在 `content_source`、`learning_content`、`content_version`、`word_sense`、`word_example`、`media_asset`、`pronunciation` 与 `vocabulary_book_word`。所有 `DATETIME(3)` 使用 UTC。

## 模型关系与发布边界

```text
vocabulary_dataset_catalog 1 ── N vocabulary_import_batch 1 ── N vocabulary_import_item
                                                     └── 1 ── N tts_generation_task

vocabulary_import_batch.target_book_id ────────────────> vocabulary_book.id
vocabulary_import_item.content_id (发布后) ─────────────> learning_content.id
tts_generation_task.asset_id (生成后) ──────────────────> media_asset.id
```

- 暂存层不替代正式词典：未完成审核、未完成音频或授权未核验的批次不得发布。
- `word_key_hash` 与 `learning_content.word_key_hash` 共同用于 canonical word 碰撞判断；命中时采用 `reuse`，不重复创建主词条。
- `object_key` 唯一，成功任务可安全重试；服务端以稳定 OSS 路径复用成功音频。
- `vocabulary_import_batch.options_json` 为批次启动时锁定的音色、采样率、SQL 导出和发布策略快照；密钥不写入该字段。

为已批准的新词义及其例句生成的可恢复任务。普通任务走 `aliyun_nls`；需要精确音素控制时可记录 DashScope/CMU 元数据。`object_key` 是跨重试的幂等键。

| 字段 | 类型 | 可空 | 默认 | 说明 | 逻辑关联 |
| --- | --- | --- | --- | --- | --- |
| id | CHAR(32) | 否 | 无 | 任务主键 | |
| batch_id | CHAR(32) | 否 | 无 | 所属批次 | vocabulary_import_batch.id |
| item_id | CHAR(32) | 否 | 无 | 对应导入行 | vocabulary_import_item.id |
| target_type | VARCHAR(16) | 否 | 无 | sense / example | 决定发布时绑定 word_sense 或 word_example |
| sense_no | INT | 否 | 1 | 义项顺序 | 支持一词多义扩展 |
| accent | VARCHAR(16) | 否 | 无 | us / uk | |
| provider_code | VARCHAR(32) | 否 | 无 | aliyun_nls / aliyun_dashscope | TTS 路由 |
| model_code | VARCHAR(120) | 是 | NULL | 特殊 TTS 的模型标识 | 审计快照 |
| voice | VARCHAR(64) | 否 | 无 | 实际音色参数，如 eva/luna | 批次参数快照 |
| generation_mode | VARCHAR(32) | 否 | 'plain' | plain / phoneme | |

| phoneme_value | VARCHAR(500) | 是 | NULL | ARPABET/CMU 音素串 | 异读词精确发音 |

| error_code | VARCHAR(64) | 是 | NULL | 最近一次失败码 | |

索引：`PRIMARY(id)`；`uk_tts_generation_object(object_key)`；`idx_tts_generation_retry(batch_id, state, attempt_count)`。

## 发布前校验

1. 数据源 `license_status` 必须为 `verified`。
2. 不存在 `review_status='pending'` 的导入行。
3. 全部 `tts_generation_task` 必须为 `succeeded`，且具备 `asset_id`。
4. 在单一事务中创建或复用 canonical word，写入 `content_version`、`word_sense`、`word_example`、`pronunciation` 与 `vocabulary_book_word`。
5. 发布后更新目标 `vocabulary_book.word_count`，并写入 `admin_audit`。

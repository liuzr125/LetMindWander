# 公告字段字典增量

沿用最新基础设计的 admin_menu、admin_role_menu、admin_audit，不改历史字典。

| announcement 字段 | 类型 | 可空 | 说明 |
|---|---|---|---|
| id | CHAR(32) | 否 | 随机公告主键 |
| title | VARCHAR(120) | 否 | 标题 |
| body | TEXT | 否 | 纯文本正文，应用上限 20000 字 |
| state | VARCHAR(16) | 否 | draft 草稿、published 已发布、withdrawn 已撤回 |
| publish_at | TIMESTAMP(3) | 是 | 发布时间；published 时必须设置，API 留空按当前时刻 |
| created_by | CHAR(32) | 否 | 创建管理员 ID |
| updated_by | CHAR(32) | 否 | 最近保存管理员 ID |
| created_at | TIMESTAMP(3) | 否 | 创建时间 |
| updated_at | TIMESTAMP(3) | 否 | 最近保存时间 |

主键 id；索引 idx_announcement_public(state,publish_at)。MySQL 5.7 不使用 CHECK 约束，状态和值限制在后端验证。管理员保存与审计使用同一事务。菜单 announcements 默认授予 SUPER_ADMIN，其他角色通过现有角色菜单授权。无公告默认数据。

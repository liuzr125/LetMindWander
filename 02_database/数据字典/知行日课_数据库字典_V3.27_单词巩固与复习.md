# V3.27 单词巩固与复习模式增量设计

基于数据库目录历史文件名 V3.16、实际内容 V3.23 合并设计及代码中的后续增量（截至 V3.26），旧版文件保留。本增量不会替代整库初始化，必须先核对并应用实际缺失的代码历史迁移，尤其 V3.20–V3.22 词书轮次记录。

## 新表

| 表 | 主键 / 约束 | 用途 |
| --- | --- | --- |
| word_study_mode | setting_id=1（服务端固定） | 全体用户统一 interval_mode=fixed / flexible，默认 fixed；仅 study_records 菜单管理员可修改，写入 admin_audit |
| word_study_cursor | owner_id | 持久化有效反馈序号，重试不推进 |
| word_study_state | owner_id, content_id | 当前词的 pending、exposed、streak、recovery、business_date、first_seen_date、eligible_position、eligible_at、source_kind、task_id、origin_task_id、schedule_id、free_study、scheduled_interval、schedule_mode、last_completed_date、version_no |
| word_study_attempt | owner_id, attempt_id | 请求内容和不可变响应回执，拒绝同 key 不同内容，避免重复点击/网络重试重复计数 |
| word_study_event | id；owner_id, attempt_id 唯一 | 反馈、词面快照、模式、阶段前后、实际间隔前后、到期日、认识反馈标记、完成状态、事件时间 |
| word_study_event_round | event_id, round_id | 反馈发生时的词书学习轮次，切书后历史关系不漂移 |

复习事件完成时同步既有 review_feedback 日汇总，学习动作继续写 learning_record / learning_event 和词书轮次统计。首次模糊/不认识曝光记 learning，首次认识即 understood 并计入已学；新词候选排除 learning 和 exposed=1。仅分配但未作答的状态 exposed=0 仍可作次日新词。

## 调度规则

新词、巩固、到期复习一次 remember（认识/记得）即当天完成，按不同词计数，从当天队列移除，不当天再次展示。fuzzy/unclear 保持待巩固；重排后先经过4个其他有效反馈或两分钟后再练，随后一次remember完成，保留recovery对跨天间隔和阶段的影响。退出不完成；跨日保留未完成pending/recovery。streak保留作历史兼容和反馈日志，不再作为两次门槛。

固定：首次完成次日；到期成功后加 3、7、14、30、60 天，之后每次 60 天。模糊补练完成后次日且阶段不推进；不认识补练完成后次日且阶段重置。固定模式继续按阶段推进，不能因模糊后的 1 天实际间隔倒退阶段。

灵活：首次完成 1 天；成功按原实际间隔×2（上限60），模糊补练完成 ceil(原间隔/2)（下限1），不认识补练完成1天。

全局模式切换不触碰当前排期、当天进度或历史。flexible→fixed 的首次后续成功选择大于原实际间隔的下一阶（例如 2→3、4→7、20→30、60→60）；随后用固定阶段推进。fixed→flexible 使用原实际间隔。模式在完成事务内读取一次，并保存到反馈快照。

服务端业务日为 Asia/Shanghai；DATETIME(3) 无时区，应用 Instant 经 JDBC 连接时区转换保存，当前 dev/local 为 Asia/Shanghai；不可把原始 DATETIME 墙钟值一概标为 UTC。review_schedule 原 TINYINT UNSIGNED stage 足够保存0–5，无须破坏性改列。旧 completed 单词迁移为上次完成日+60的维护复习；既有 active / paused 到期日保持。灵活转固定时的模糊补练，按反馈前实际间隔映射到不大于该间隔的固定阶段；补练后次日复习，此后继续下一阶。灵活阶段是便于查看的固定阶梯映射，不表示预测记忆强度。

无法从旧记录确定实际间隔时以旧阶段0/1/2/3对应1/3/7/14天带入，并在审阅中披露。

## 迁移与回退

SQL 为 MySQL5.7.25 使用 InnoDB、utf8mb4、DATETIME(3)，无 JSON 默认值、窗口函数、ADD COLUMN IF NOT EXISTS 等不兼容语法。只准备，不执行。先备份，副本演练后应用；与应用版本同步上线。回退应用前需要导出新表及审计，恢复原 completed 排期应从备份恢复，不能删除用户学习记录。

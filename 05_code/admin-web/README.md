# 脑袋开小灶 Vue 管理端

Vue 3 + Vite 管理端。已实现用户、邀请码、概览、内容覆盖、英语单词以及 AI 模型与费用管理。“用户状态”的“账号列表/邀请码”页签可正常切换；账号列表支持搜索、状态筛选、分页，并且只显示脱敏管理信息。“内容与来源”页可从技术主题进入已发布内容列表，支持主题筛选、搜索、分页和只读详情，并展示正文、审核状态、来源与许可。“英语单词”会按词书展示实时成员数和所有单词，默认 20 条/页，可切换 10/20/50/100 条；每行“查看详情”可查看音标、词义、例句、来源、许可和发音，无音频时可由管理员触发服务端 TTS。AI 页支持添加/编辑模型、Flash/Pro 规格、默认模型、价格版本、加密密钥录入、月预算和脱敏调用账本；“语音合成”页集中管理阿里云 TTS 地址、英语音色、AppKey/AccessKey 和脱敏调用日志。小程序用户无权修改这些配置。

```bash
pnpm install
pnpm dev
```

本地开发通过 Vite 将 `/api` 代理到 `http://127.0.0.1:8025`。首次进入需要输入后端 `ADMIN_TOKEN`，本地默认值为 `dev-admin-token`。令牌只保存在当前浏览器的 localStorage。

生产构建：

```bash
VITE_API_BASE_URL=https://api.example.com/api pnpm build
```

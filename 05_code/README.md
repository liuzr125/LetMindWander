# 项目代码目录

采用前后端分离：Vue 管理端和微信小程序分别调用 Java 后端接口。管理端业务逻辑在 Java 后端实现。

| 目录 | 技术与用途 |
| --- | --- |
| admin-web | Vue 管理端：页面、组件、路由、接口请求与静态资源 |
| backend | Java 后端：管理端接口、小程序接口、业务逻辑与数据库访问 |
| miniprogram | 原生微信小程序：后续使用微信开发者工具开发 |
| docs | 接口、开发、联调与部署文档 |
| scripts | 后续开发、部署辅助脚本 |

按用户要求，本次只创建目录及空文件，不写代码、不安装依赖。package.json、pom.xml、app.json 等配置文件也为空占位，尚不能构建、启动或直接导入运行。后续开发时再填写。

Java 暂用 com.zhixing 作为目录包路径，可在正式初始化时调整。需求在 ../01_需求文档/当前版本；数据库在 ../03_数据库。代码区不重复复制建表 SQL。

## 本轮改造

书籍页面新增「接入配置与就绪检查」，支持配置生成任务开关、兼容图像接口／模型／密钥、书源地址和授权全文模板，以及图像和 TTS 单价、单任务预算。

参数保存到已有 `app_parameter` 表，即时读取，不需要再次执行 V3.30，也不需要为每次配置修改重启。服务首次加载本轮代码需要重启本地后端。

密钥只写不回显；留空保留已有密钥；更换服务域名要求同时填写新密钥。配置更新使用版本冲突检查并记录脱敏审计。存在排队或运行任务时需先暂停，再更换书源／图像提供方及凭据。

运行时关闭开关会在当前外部调用返回后的安全检查点暂停任务，不宣称能撤销已提交调用或费用。暂停期间修改服务地址后，旧任务需重新建立以避免使用不匹配的书源或生成参数。

输入“小王子”时，将“小公主”“跛脚小王子”等分到「其他相近书目」中，不再将其显示成目标书的匹配版本。

## 外部配置注意事项

图像每张及 TTS 每千次计费调用的人民币单价需要按用户套餐／服务商报价填写，不能用猜测值替代。阿里云短文本 TTS 每次请求按每 100 个有效字符向上取整；已有旧的“每百万字符”配置不会被重新解释。

已有 TTS／OSS 配置通过就绪状态复用；该状态表示配置存在，不等于真实上传或合成已验证。授权书源缺失时仍可导入已获授权的 EPUB／TXT／Markdown；不将相近作品或 AI 生成内容冒充目标原著。

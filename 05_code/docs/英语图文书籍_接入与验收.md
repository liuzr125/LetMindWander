# 英语图文书籍：接入与验收

日期：2026-11-01。业务入口：管理端「英语角 → 英语书籍」，小程序「学习 → 英语 → 书籍」。

## 已实现范围

- 合作正版书源优先、公版书目补充的书名检索；候选版本及来源展示。未配置出版社合作接口时，不声称已取得出版社全文。
- 授权 UTF-8 TXT、Markdown、未加密 EPUB 导入；EPUB 按 spine 排序并提取可用内嵌图片。
- 草稿编辑、章节和段落稳定标识、配图预览、章节排序、完整性及来源确认。
- AI 原创按大纲逐章生成；已有作品不通过 AI 补写成伪原著。
- AI 章节配图、全书或单章生成、指定章节新版本重生成。
- 英文 TTS 分段、MP3 时长解析、OSS 持久化、完整章节播放清单。
- 任务队列、暂停／继续／取消、进程失联租约恢复、缓存复用、上传独立重试、结果不明的请求人工核对及结果恢复。
- 发布快照与草稿分离；全文、图片、音频及使用依据齐备才可发布。
- 小程序书库／书架、目录、图文及可选译文、字号、点词、生词来源、章节听读、倍速、全章拖动、连续下一章、进度接续及冲突处理。

## 数据库和权限

1. 先在备份副本执行 `backend/sql/V3.30_english_reading_books.sql`，核验后再按部署流程升级正式库。脚本依赖现有菜单／角色结构和 V3.28 英语角菜单，不执行删除或重建。
2. 新增五张表：`english_reading_book`、`english_book_job`、`english_book_generation`、`english_book_progress`、`english_book_word_source`。
3. `english_books` 是独立管理权限。迁移默认只授予 SUPER_ADMIN，其他角色由角色管理显式分配。原短文和词书权限不扩大。
4. `schema.sql` / `data.sql` 同步供隔离测试；正式环境不自动运行建表脚本。
5. 生成任务关闭时仍可编辑和导入草稿。缺少迁移时须先完成迁移才能访问书籍接口。

## 配置

服务启动环境变量（由 `application.yml` 映射）：

| 变量 | 用途 | 默认 |
| --- | --- | --- |
| `BOOK_WORKER_ENABLED` | 启用异步书籍任务，迁移和供应商配置完成后设 true | false |
| `BOOK_LICENSED_CATALOG_URL` | 合作正版书源 API 根地址，见下方协议 | 空 |
| `BOOK_CATALOG_URL` | Gutendex 兼容公版书目 API 根地址；持续生产使用建议部署自有目录服务 | https://gutendex.com |
| `BOOK_SOURCE_TEXT_URL_TEMPLATE` | 已确认允许自动下载的 UTF-8 全文 URL，必须包含 `{id}`，例如 `https://authorized.example/text/{id}.txt` | 空 |
| `BOOK_IMAGE_ENDPOINT` | 兼容下述 JSON 协议的图像生成 HTTPS 接口 | 空 |
| `BOOK_IMAGE_MODEL` | 图像模型标识 | 空 |
| `BOOK_MAX_JOB_COST` | 图像／音频单任务预计费用上限，单位人民币 | 30 |

后台「系统参数」中保存：

| 参数 | 内容 |
| --- | --- |
| `BOOK_IMAGE_API_KEY` | 图像服务密钥，勾选敏感参数，使用现有加密机制 |
| `BOOK_SOURCE_API_KEY` | 合作书源需要鉴权时填写敏感参数；可选 |
| `books.image.unit_price` | 单张图像人民币正数单价，未设置时禁止图像生成 |
| `books.tts.price_per_thousand_calls` | 阿里云短文本 TTS 每千次计费调用的人民币正数价格，未设置时禁止音频生成 |

音频复用现有阿里云 TTS 的 AppKey、AccessKey 或 NLS Token 及 OSS 配置。书籍音频固定 16000 Hz、正常合成语速；播放器倍速不重新合成。图像接口、合作书源和全文下载只允许公网 HTTPS，不跟随重定向，不请求私有网络地址。

图像／音频按任务的用量及价格快照检查费用。TTS 按每次请求每 100 个有效字符向上取整计费，中文汉字按 2 个有效字符计算，任务记录实际计费调用次数。这里的费用是按配置单价的估算，不是供应商最终账单。正文 AI 生成继续使用现有 AI 模型、月预算与调用账本。

## 合作正版书源协议

这是产品预留的合作适配协议，需要将已取得使用授权的出版社／作者接口映射到该格式；没有默认对接任何商业出版社。鉴权配置后使用 `Authorization: Bearer <BOOK_SOURCE_API_KEY>`。

- `GET {root}/books?language=en&search={urlencoded term}` 返回：

```json
{"results":[{"id":7,"title":"An Authorized Book","author":"Author","edition":"English edition","sourceUrl":"https://publisher.example/books/7","licenseNote":"具体授权依据","rightsScope":"投放地区及用途"}]}
```

- `GET {root}/books/7` 返回完整 UTF-8 正文及可选授权图片：

```json
{"text":"# Chapter 1\n\nComplete English paragraphs.\n\n# Chapter 2\n\nMore complete text.","images":[{"chapterIndex":0,"paragraphIndex":0,"base64":"图片文件的 Base64","caption":"Scene","licenseNote":"插图授权依据"}]}
```

章节、段落下标均从 0 开始。响应总大小不超过 2 MB；较大的图文书可采用 EPUB 授权文件导入。图片经校验后存入 OSS。所有候选均标记为待核实具体版本和用途，不将目录中的美国公版字段直接当成本产品投放地区的可收录确认。

公版下载仅使用配置的许可下载渠道；不自动抓取 Gutenberg 主站。目录检索不能保证存在某一本书的可收录全文，未取得《小王子》具体版本时仍需授权或其他可用版本。

## 图像服务协议

通用兼容接口请求 JSON：`model`、`prompt`、`n:1`、`size:"1024x1024"`、`response_format:"b64_json"`，Bearer 鉴权。火山方舟 Seedream 使用 `size:"2K"`、`stream:false`，Lite／4.x 模型增加 `sequential_image_generation:"disabled"`，不发送通用接口的 `n` 字段。

返回 JSON：`{"data":[{"b64_json":"..."}]}`，支持 JPEG、PNG、WebP，单图不超过 5 MB。供应商只返回 URL 时，需要在适配层转成该格式，系统不随意下载模型返回的任意 URL。

全书人物外貌和画风作为每章共同提示词；实际视觉一致性由模型和管理员预览核验，不能仅凭任务完成状态保证。

## 任务恢复和存储

- 每个付费调用前记录步骤；响应先进入临时二进制检查点，随后上传 OSS。上传失败重试不再次合成。
- OSS 与媒体元数据保存成功后清除二进制检查点，只保留对象引用、状态及音频时长。尚未上传的临时结果保留用于恢复。
- 同一正文、音色、生成参数和生成版本复用成功资源；强制重生成采用新的章节生成版本。
- 服务超时、失联或无法确认调用是否成功时不自动重发。后台显示待核对步骤，可导入供应商已经返回的 MP3／图片／JSON 结果再继续；确认供应商没有结果后可显式允许重新提交。
- 多实例采用任务领取及租约保护。默认失联租约 30 分钟；暂停期间修改草稿后需要新建任务，以免旧参数继续处理。
- 任务取消不撤销供应商已提交请求和已发生费用。已成功资源保留，发布内容不受草稿失败影响。
- 所有书籍媒体使用 `book_image`／`book_audio` 用途，不通过现有公共词条媒体路由开放。访问前检查已发布快照引用；后台通过独立权限预览草稿。
- 私有 OSS 签名地址有效期 5 分钟，过期重新获取；下架停止新签名，已签名访问最多延续到有效期届满。
- 未配置自动资产清理策略：旧版本、已取消任务的成功资源保留，后续清理必须核对发布快照和草稿引用。

## 小程序运行边界

- 本版使用前台音频上下文，切到后台暂停并保存；后台持续播放需要单独接入和真机验收。
- 拖动条按章节总时长映射至对应音频片段及偏移，用户看到整章进度。
- 逐句高亮、自动生成中文译文、离线缓存、跟读评分、动画未纳入本次实现。后台可以录入已有逐段译文。
- 域名配置需允许后端请求域名及 OSS 图片／音频域名；使用私有 Bucket，不能将密钥放入小程序。
- 微信开发者工具和真机的图片加载、音频连续切换、弱网恢复、屏幕退出行为仍需在部署配置完成后验证。

## 验收入口

1. 新建书籍并保存具体版本、使用依据、投放范围及各项许可确认。
2. 选择书源采集、导入授权 EPUB／TXT／Markdown，或以独立书名生成 AI 原创。
3. 预览并整理章节，补齐配图；配置音色后生成全书音频。
4. 核对完整性、发布检查、发布。尝试在草稿中修改正文，确认线上正文与音频保持旧版成套内容。
5. 小程序进入英语书籍，阅读、点词加入生词本、播放／拖动／倍速、切章、完成章节、退出后继续。
6. 模拟上传失败、签名过期、生成结果不明及两端进度冲突，检查恢复和避免重复计费的行为。

隔离测试不连接正式业务库，不请求真实收费服务。自动化测试记录在同目录的验收记录文件中。

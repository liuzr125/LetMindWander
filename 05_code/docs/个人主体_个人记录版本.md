# 个人主体：个人记录版本

修改日期：2026-11-02。适用源码：LetMindWander/05_code。

## 功能调整

- 保留笔记、问题卡、标签、草稿、编辑、删除、个人复习和学习功能。
- 创建页、列表和详情固定为“仅本人可见”，不提供可见范围选择。
- 删除小程序的好友与共享入口、六组好友及共享页面、页面注册和相应请求方法。
- 个人资料移除公开和好友可见选项；恢复的旧草稿也按私有提交。
- 删除好友 HTTP 控制器和知识共享好友列表接口。旧客户端访问好友/共享接口返回 404。
- 知识创建、编辑和旧版可见范围接口只允许 private；friends 和 selected 返回 400 / PRIVATE_RECORDS_ONLY。
- 知识详情、列表以及关联笔记原文继续按登录用户归属查询。历史 friends/selected 记录在接口中按私有呈现，旧授权不会开放跨用户读取。编辑或设为私有时会清理该条记录的共享规则。
- 原有历史好友关系与共享规则表保留，不执行线上数据清理。

## 验证

- 小程序 Node 测试 46 项通过，包含草稿/正式保存固定私有、删除菜单、页面移除和个人资料旧草稿恢复。
- 后端 F06KnowledgeLibraryIntegrationTest、F07LearningPageIntegrationTest、F09MineSecondaryPagesIntegrationTest 共 3 项集成测试通过，使用隔离 H2 数据库。
- 验证旧共享记录、有效好友关系与旧授权存在时，非作者仍无法读取，旧共享接口返回 404，不能重新开启共享。
- 已检查四个修改页面的标记结构和全部 40 个注册页面文件。尚未在微信开发者工具内进行真机预览或提审。

## 发布顺序

1. 后端使用干净构建（例如 mvn clean package）重新部署，避免旧 target 中残留已删除的 FriendController.class。确认旧好友及共享接口均返回 404、共享范围写入被拒绝。
2. 在微信开发者工具导入更新后的小程序源码，检查新建、编辑、草稿、删除、复习以及“我的”页面，再上传新版本。前端与后端必须同步更新；单独上传前端不会关闭旧后端接口。
3. 在公众平台按完整产品实际功能检查服务类目、简介及提审说明。此次修改仅处理个人记录与社交分享边界，不代表其他功能和类目已通过审核。

没有修改微信账号主体、线上数据库、支付或认证设置；没有部署或提交审核。

## 可用的提审说明

以下文案应在新后端与小程序均已更新、人工验证完成后使用：

> 本小程序的笔记和问题卡用于用户个人记录、整理与复习，内容仅创建者本人可查看、编辑和删除。本次已移除好友与共享、可见范围设置及好友阅读功能，服务端已关闭共享访问接口，并限制记录仅本人访问，不提供用户原创内容的发布分享和社区交流功能。

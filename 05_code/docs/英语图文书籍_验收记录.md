## 覆盖的主要行为

- 正文或媒体不完整时拒绝发布，发布内容与后续草稿编辑隔离。
- 修改正文清除对应音频映射及完整性确认；按旧发布书名／难度搜索不受新草稿影响。
- 长章节按 Unicode 安全边界分段，所有原文保留；校验 MP3 帧并计算真实时长。
- 上传失败保存临时响应，重试不再次请求 TTS；上传成功后清除数据库二进制缓存。
- 已有音频缓存复用，付费调用结果不明时不自动重发。
- 任务暂停／恢复、重复启动保护，权限迁移可重复执行且不自动扩大普通编辑权限。
- EPUB 按 spine 顺序读取，保存内嵌插图关联；错误／超大文件拒绝导入。
- 合作正版目录优先，某一书目服务失败不隐藏其他书源；书目中的版权字段不自动转成收录许可。
- 用户学习记录隔离、乐观版本冲突、完成章节去重、断点续听、跨片段定位和离页播放防护。

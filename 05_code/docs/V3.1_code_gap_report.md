# V3.1 需求与代码核对

核对基线：`01_Requirements/知行日课_需求规格说明书_V3.1.docx`，重点为第 13 章。

## 本次已完成

- S12/S13/S14/S15 核心链路：词条详情读取已审核提示，选择认义/拼写，遮答案作答，服务端判定，结果页返回真实统计。
- 每组 1—5 词；小程序首个入口先支持词条详情的单词训练，后端接口已支持多词冻结。
- 标准答案不在 GET 响应中下发；首字母、线索和揭示答案均先写入提示事件。
- 首答和重试不覆写；错题在其他首答后回补，每题最多两次追加尝试。
- 会话可恢复，支持部分完成；写接口使用 `Idempotency-Key` 和 `expectedVersion`。
- 训练、“已理解”、生词本和复习保持独立；只有用户在 S12 显式选择后，已练词才加入复习。
- 结果区分无提示首答正确、提示后正确、重试正确、首次错误、未测和待巩固词，并显示真实复习状态。
- 功能开关已分为基础记忆、听词、AI 子场景和稳定标签；后三项默认关闭。
- 记忆作答请求体不写入访问日志；开发数据库密码已改为环境变量。
- 增加 MySQL 5.7.25 增量和破坏性回滚脚本，并与 V3.1 空库基线做过实际导入/回滚演练。
- 英语新词已增加词书前置选择；未选时不会从全库产生新词，选定或更换后今日未开始任务只来自当前词书。
- 已增加当前词书进度页：服务端统计总数、已学、剩余和完成率，支持全部/已学/未学分页查看；已学口径为 `understood/mastered`。
- 计划每日时间已支持直接输入；时间范围、快捷值、星期、难度、数量上限、默认值和预算估算参数统一从 `app_parameter` 的 `plan.*` 数据字典读取，前后端共用同一校验口径。
- 词书进度已按当前计划每日新词数计算预计剩余天数；每日新词为 0 时提示调整计划，不伪造完成日期。

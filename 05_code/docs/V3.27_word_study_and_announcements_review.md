## 行为

新词、巩固、到期复习一次“认识/记得”即当天完成，按不同词计数，同词当天不再出现。模糊或不认识保留当日待巩固，隔4个其他有效反馈或2分钟后允许再练，随后一次认识完成；退出不完成。跨北京时间零点保留未完成 pending/recovery。客户端保存成功后才能换词，不做猜测完成或乐观加数。

固定间隔累计按时为第1/4/11/25/55天，之后每60天维护。灵活间隔首次1天，成功×2上限60、模糊补练ceil(原间隔/2)下限1、不认识补练1天。全局默认固定；只在管理端词书学习记录页修改，切换仅影响后续完成反馈。flexible→fixed成功用大于原实际间隔的下一阶；模式切换时的模糊补练映射原实际间隔到已达固定阶段，次日后继续下一阶。

小程序原页面和三按钮保留，原答案显示设置保留，不新增学习入口或强制隐藏释义。反馈后在原页切换下一词；返回首页、词书进度与每日词列表读取服务端真实完成数。已学为当前词书 learning_record 中 understood/mastered 的不同词数，首次认识即置 understood。新词排除已学、已经曝光/学习及已加入active复习的词，复习与巩固不消耗新词名额。词书轮次和重新学习历史保留。

管理端词书学习记录和轮次详情追加逐词反馈：用户、词面快照、词书轮次、时间、反馈、模式、阶段、实际间隔、下次复习日期。新引擎同步既有learning_event、review_feedback和词书统计。旧的一次完成单词接口返回WORD_STUDY_REQUIRED，以防绕过新规则；非单词内容接口不变。

公告可保存草稿、定时发布、撤回；普通用户只能查看已发布且时间已到的正文，草稿/未来/撤回详情404。管理员权限使用新增announcements菜单，操作进入admin_audit。没有创建真实公告。

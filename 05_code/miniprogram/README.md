# 脑袋开小灶·原生微信小程序

这是小程序前端骨架，使用 WXML、WXSS、JavaScript 和 JSON。业务数据统一通过 HTTP API 访问 Java Spring Boot 后端；小程序内不包含云函数、数据库直连或 OSS 密钥。

## 目录

- `pages`：首页、学习、问一问、知识库、我的五个底部入口；成长详情由首页摘要进入。问一问的默认模型仅能在 Web 管理端修改。
- `components`：通用小程序组件。
- `services`：统一 HTTP 请求和后端服务封装。
- `config`：按小程序版本区分的 API 地址。
- `utils`：无业务状态的通用工具。
- `assets`：本地静态资源。

## 本地启动

1. 先启动 Spring Boot 后端，本地默认端口为 `8025`；小程序实际 API 地址以 `config/index.js` 的当前环境为准。
2. 安装并打开微信开发者工具，选择“导入项目”。
3. 项目目录选择当前 `miniprogram` 目录。
4. 骨架使用 `touristappid` 便于首次导入；需要登录、真机调试或上传时，在开发者工具中换成团队的正式 AppID。
5. 点击“编译”，首页应显示“脑袋开小灶”和基础占位卡片。

## 开发环境的域名校验

`project.config.json` 中暂时设置了 `urlCheck: false`，便于开发者工具访问本地 HTTP 后端。也可在开发者工具的“详情 > 本地设置”中勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。该设置只适用于本地开发，真机和生产环境仍受微信平台规则约束。

## 待配置

- 将 `config/index.js` 中的体验版、正式版 `example.com` 占位地址换成已备案的 HTTPS API 域名。
- 在微信公众平台配置对应的 `request` 合法域名。
- 与后端确认接口前缀、响应结构、登录换取 token 流程及错误码约定。
- OSS 上传如需临时凭证，必须由 Java 后端签发；不得在小程序中内置 AccessKey。
- 短文朗读由后端调用阿里云 TTS 并缓存到 OSS。小程序只接收受控音频地址，生产环境还需将实际音频下载域名加入微信合法域名。

## 英语短文朗读与跟读

短文详情支持整篇朗读、0.75x—1.5x 本地变速、录音跟读和云端回放。用户首次使用时需单独同意录音上传；录音由服务端写入阿里云 OSS 私有对象，通过本人鉴权后的短时签名地址播放。同一用户、同一短文只保留最新录音，新录音替换旧录音，用户可在短文页主动删除。点选正文中的英文单词会先查正式词库，再查短文补充词表，展示音标、释义和发音；V3.13 预置短文的 104 个词形由 V3.14 迁移补齐。“解释这段内容”只把当前段落带到问一问，已授权时自动提问，未授权时必须先由用户确认；仍使用统一的模型、预算、费用与日志机制。当前“跟读”不包含发音评分；如需评分，应另接语音评测/ASR 服务并再次核对隐私披露。

骨架无 npm 依赖，不需要执行安装或构建命令。
# 知行日课微信小程序

原生微信小程序工程。F01 已实现：

- U16 受邀准入：邀请码、协议确认、微信登录、错误态和表单状态保留。
- U46 注册确认：微信头像、昵称、手机号授权、注册提交和字段级错误。
- 会话恢复：本地安全保存服务端会话令牌，请求自动携带 Bearer Token。
- V3.1 英语记忆：词条详情的审核提示，认义/拼写设置、遮答案作答、有限回补、中断恢复和结果页。
- 词书前置选择：点击“英语新词”时先确认当前词书；未选时进入词书列表，选定后直接开始该词书的今日新词。
- 词书进度：可从“我的 > 词书学习进度”或词书选择页进入，查看已学、剩余、总数和完成率，并按全部/已学/未学查看单词详情。
- 计划时间可直接输入或用加减按钮调整；快捷时间、范围、星期、难度和数量上限由后端计划数据字典下发，不在页面写死。
- 学习页的学段、难度和生词状态筛选由后端学习数据字典下发；词汇页使用同一行紧凑下拉筛选，不再在页面重复写死标签和值。
- 词书进度会按当前计划的“英语新词/天”展示预计剩余学习天数，修改计划后重新进入即可看到新估算。

## 联调

1. 用微信开发者工具导入本目录。
2. 启动后端 `backend`，本地默认接口地址为 `http://127.0.0.1:8025/api`。
3. 开发者工具中开启“不校验合法域名”仅用于本地联调。
4. 先在管理端生成邀请码，再从 U16 进入。开发环境手机号授权失败时自动使用 `138 **** 8000` 模拟凭证。

体验版和正式版必须在 `config/index.js` 配置有效 HTTPS 域名，并在微信公众平台登记 request 合法域名。小程序中不得保存 AppSecret。

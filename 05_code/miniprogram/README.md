# 脑袋开小灶·原生微信小程序

这是小程序前端骨架，使用 WXML、WXSS、JavaScript 和 JSON。业务数据统一通过 HTTP API 访问 Java Spring Boot 后端；小程序内不包含云函数、数据库直连或 OSS 密钥。

## 目录

- `pages`：今日、学习、知识库、成长、我的五个首批页面。
- `components`：通用小程序组件。
- `services`：统一 HTTP 请求和后端服务封装。
- `config`：按小程序版本区分的 API 地址。
- `utils`：无业务状态的通用工具。
- `assets`：本地静态资源。

## 本地启动

1. 先启动 Spring Boot 后端，开发环境默认地址为 `http://127.0.0.1:8080/api`。
2. 安装并打开微信开发者工具，选择“导入项目”。
3. 项目目录选择当前 `miniprogram` 目录。
4. 骨架使用 `touristappid` 便于首次导入；需要登录、真机调试或上传时，在开发者工具中换成团队的正式 AppID。
5. 点击“编译”，首页应显示“脑袋开小灶”和基础占位卡片。

## 开发环境的域名校验

`project.config.json` 中暂时设置了 `urlCheck: false`，便于开发者工具访问本地 HTTP 后端。也可在开发者工具的“详情 > 本地设置”中勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。该设置只适用于本地开发，真机和生产环境仍受微信平台规则约束。

骨架无 npm 依赖，不需要执行安装或构建命令。
# 脑袋开小灶微信小程序

原生微信小程序工程。F01 已实现：

- U16 受邀准入：邀请码、协议确认、微信登录、错误态和表单状态保留。
- U46 注册确认：微信头像、昵称、手机号授权、注册提交和字段级错误。
- 会话恢复：本地安全保存服务端会话令牌，请求自动携带 Bearer Token。

## 联调

1. 用微信开发者工具导入本目录。
2. 启动后端 `backend`，默认接口地址为 `http://127.0.0.1:8080/api`。
3. 开发者工具中开启“不校验合法域名”仅用于本地联调。
4. 先在管理端生成邀请码，再从 U16 进入。开发环境手机号授权失败时自动使用 `138 **** 8000` 模拟凭证。

体验版和正式版必须在 `config/index.js` 配置有效 HTTPS 域名，并在微信公众平台登记 request 合法域名。小程序中不得保存 AppSecret。
